# Personalized learning and review

Read this reference for candidate tests, first learning, due reviews, or transfer tests.

## Choose the test from the goal

- `recognition`: understand the expression in a new sentence without relying on the original translation.
- `production`: express the intended meaning from a Chinese cue, situation, or communicative goal.
- `listening`: recognize the expression from audio only when the environment can actually provide audio.

Do not collapse these into a single mastered flag. A learner may recognize a phrase but be unable to produce it.

## Build a memory connection

For each weak item, choose the smallest useful combination of:

- A current real task.
- A familiar, confirmed setting.
- A word or concept the learner already knows.
- A contrast with a confusable expression.
- A short story containing multiple items, only if it remains natural.

State the semantic boundary. Personal relevance does not excuse an unnatural English sentence.

When the scene is inferred or invented, call it a practice scenario. Do not write as if it definitely happened.

## Run the attempt

1. Give a concise explanation and one natural example.
2. Remove the target expression.
3. Ask for recall or task completion.
4. Wait for the learner's response before showing the answer.
5. Give specific feedback on meaning, grammar, collocation, and naturalness.
6. Ask for a new-context transfer only when it adds information; do not turn every item into a long lesson.

Use self-ratings only after observable feedback:

| Feedback | Meaning |
|---|---|
| `again` | Could not retrieve or meaning was wrong |
| `hard` | Retrieved with major effort or material prompting |
| `good` | Correct with ordinary effort |
| `easy` | Immediate, confident, and transferable |

Record response time when it can be measured without disrupting the session. Never infer a fast response from fluent-looking prose.

## Vary retrieval context

The first personalized scene helps encoding. A later review should change at least one of:

- Surface wording.
- Speaker or audience.
- Concrete situation.
- Direction: English-to-meaning versus meaning-to-English.

Mark a review as a transfer test only when the answer is tested in a genuinely changed context.

## Session size

Default to 3–5 learning items or the number that fits the learner's time. Serve due reviews before new items. End before fatigue makes the feedback meaningless.

The scheduler in the local store is an SM-2-style baseline. It is not the product's claimed innovation. Preserve the event data needed to compare strategies later: item, mode, feedback, response time, strategy, personalization, and transfer-test status.
